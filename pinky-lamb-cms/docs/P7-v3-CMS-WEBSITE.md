# P7 v3 — real CMS website, local only

Approved scope: source :5010 → CMS drafts and media → Admin publication → immutable CMS release → :4189. No :5010 activation or cloud action. Original hosting backup remains read-only.

Current workflow (19 October 2026, [PUBLISH-SELECTED-001](../tasks/PUBLISH-SELECTED-001.md)): open the saved resource/locale and choose **Xuất bản**. This single action publishes that exact saved revision to :4189. The separate **Xuất bản website** action has been removed. **Khôi phục bản website trước** remains available. Historical seed/media tools remain separate and are not part of normal publication. Seed is a one-time, resumable source-bound command. It preserves before-images and creates new draft revisions. It does not delete old publications or media. Publication uses normal authenticated services and stores immutable snapshots. A failed public update keeps the prior website; already published CMS snapshots remain visible in history.

Private source, CMS before-images, idempotent operation journals and translation review live under `.local/p7-v3/`. No bearer token or password is stored there. Media use the normal upload, processing, quota and READY pipeline. Brand diagonal, favicon and fonts remain pinned template resources. Original media hashes are retained; public media are validated CMS derivatives. Selected publication requires an existing real CMS website release and a fresh selected draft compatible with that release. It does not require other current drafts or approval pointers to be fresh. It preserves all other active snapshots and media bytes. Missing live content, shared-source/media drift or an incompatible renderer blocks the action rather than including other changes.

English headings belong to shared Home content. Locale editors show those fields as read-only. EN/JA body translations retain the source facts, names, dates and scope. Translation review is by the implementing agent, not a claim of independent native-language certification.

The independent :4189 host follows `.local/p7-v3/website-current.json` atomically. It exposes only GET/HEAD release files, no publish API. Restart preserves the pointer. Publish and rollback require a current OWNER through the canonical Admin API at :5273; ordinary editors cannot run them. Backend restarts do not stop :4189. Active jobs stop on error and are never auto-retried. The seed journal permits explicit continuation with the same action payloads and operation keys.

Normal operation: edit and save Draft, preview, then select **Xuất bản** for the exact resource and locale. The server freezes that revision, replaces only its pin in the active frozen bundle, packages the candidate and switches :4189. The UI reports website success only after all three served HTML documents match the candidate. Packaging failures keep the old site; switch/HTTP failures restore the old pointer when the failed command still owns it. CMS history remains immutable. Retry retains the command identity and exact publication intent, including after a lost response/page reload. No other draft or staged CMS approval is included. A restored website carries its matching private frozen bundle so later selected publication can continue. There is no dependency on the private CMS API or :5010 while visitors read an exported release. Canonical URLs still target the approved future origin :5010; :4189 remains noindex local acceptance.

QA status is recorded separately after the single final campaign. This document describes implemented behavior and is not acceptance evidence.
